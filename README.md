# Seguimiento de estados del expediente (HU-10)

Práctica S11 - Diseño de Software, Universidad Continental.
Sistema Multi-Agent para gestión de expedientes municipales.

## Arquitectura
Hexagonal (dominio, aplicación, adaptadores) con los patrones State, Command, Facade, Repository y Observer.

## Ejecutar pruebas
```
pip install -r requirements.txt
python -m pytest -v
```
